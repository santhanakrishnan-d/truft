# Truft operations preview

A static walkthrough of how Truft could run — public face, sample house, office — for sharing with Truft.

This is **not** [truft.com.au](https://truft.com.au). Photography is from the live site. The mock is not wired (WhatsApp, Ask Truft, BuildPass, Xero).

## Live URL

https://bitfoundry-ai.github.io/truft/

Preferred custom domain, after a DNS CNAME is added at the registrar (GoDaddy / domaincontrol):

```
truft.bitfoundry.ai   CNAME   bitfoundry-ai.github.io
```

Do not change the apex `bitfoundry.ai` (Zoho). Do not add the GitHub Pages `CNAME` file until that record exists — otherwise the github.io URL would redirect to a hostname that does not yet resolve here.

## Local

Open `index.html` as a file, or this Pages URL. Assets sit beside the HTML.
